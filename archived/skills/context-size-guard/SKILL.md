# Context Size Guard

Explicit, readable tracking of context consumption. All KB sizes are pre-calculated
and published in `.ai-context/.context-sizes.json` (generated by `aictx sync`).
The model reads this manifest on every prompt and calculates cumulative load before
deciding to load agents or skills.

## Thresholds

| Status | Total KB | Action |
|--------|----------|--------|
| 🟢 Safe   | ≤ 40 KB  | Continue normally |
| 🟡 Warn   | 41–80 KB | Continue with yellow label — alert user |
| 🔴 Block  | > 80 KB  | **Stop and request user authorization before proceeding** |

## KB Baseline

**P0 baseline** is `baseline.total_kb` from the manifest (rules + meta skills).

## When You Load an Agent or Skill

1. Check its KB size in `.ai-context/.context-sizes.json`
2. Calculate: **baseline.total_kb + agent/skill KB**
3. If total ≤ 80 KB → load normally
4. If 41–80 KB → emit yellow label, continue
5. If > 80 KB → emit red block message and ask user before proceeding

## Output Label Format

Use the following highly compact single-line format for ALL responses. Extract sizes strictly from `.ai-context/.context-sizes.json`.

**Green (safe):**
```
🟢 **Load:** 25.4 KB Context (📜 12.4 | 🤖 8.0 | 🎯 5.0) | 📁 12.0 KB Workspace (2 files)
```

**Yellow (warn):**
```
🟡 **Load:** 60.0 KB Context (📜 12.4 | 🤖 25.2 | 🎯 22.4) | 📁 12.0 KB Workspace (2 files)
→ Ask user: continue anyway?
```

**Red (block):**
```
🔴 **Load:** 95.0 KB Context (📜 12.4 | 🤖 13.5 | 🎯 69.1) | 📁 0.0 KB Workspace (0 files)
  
→ Stop here. Output:

**Context overload detected.** This request would load 95 KB of artifacts.
The safe limit is 80 KB. This may degrade reasoning and waste tokens.

**Authorize anyway?** Reply `yes` / `authorize` to continue, or tell me which artifacts to skip.
```

## Workspace Read Size

When you need to read files from the current workspace/repository, report their size separately from the AI context in the `Workspace` branch of the label.

### Method

- Rely on the output of tools like `view_file` which return exact byte counts automatically.
- Do NOT run bash scripts (like `du` or `wc`) manually just to check sizes, to avoid wasting steps.
- Exclude `.ai-context` artifacts from the workspace calculation (they are already counted in Context Load).

### Workspace Thresholds

- Safe: ≤ 200 KB
- Warn: 201–800 KB
- Block: > 800 KB (ask for authorization before reading)

## Key Principle

No hidden scripts. The model **reads the manifest** and acts on it declaratively.
Enforcement is transparent and always visible.
